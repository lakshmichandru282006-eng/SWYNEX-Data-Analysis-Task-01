# SWYNEX Internship – Task 1: Data Cleaning & Preparation

## Project Overview
This project focuses on cleaning and preparing a Medical Appointment No-Shows dataset using Python and Pandas as part of my Data Analytics Internship at SWYNEX Technologies.

## Dataset Information
- **Dataset:** Medical Appointment No-Shows
- **Original Records:** 110,527
- **Columns:** 14
- **Tools Used:** Python, Pandas, NumPy, Google Colab

## Data Cleaning Steps
- Inspected the dataset and checked for missing values.
- Checked and removed duplicate records.
- Standardized column names to lowercase.
- Removed unnecessary leading and trailing spaces from text values.
- Converted date columns into proper datetime formats.
- Converted patient and appointment IDs into string data types.
- Identified and handled invalid negative age values.
- Validated the cleaned dataset.

## Final Results
- **Final Records:** 110,526
- **Total Columns:** 14
- **Duplicate Records:** 0
- **Missing Age Values:** 0

## Files Included
- `Raw_Dataset.csv` – Original dataset.
- `Cleaned_Dataset.csv` – Cleaned dataset.
- `Data_Cleaning_Task_01.ipynb` – Python notebook containing the cleaning process.

## Key Learning
Gained practical experience in data inspection, data cleaning, handling missing and invalid values, correcting data types, and preparing datasets for further analysis.
